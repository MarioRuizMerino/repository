# Tarea inicial de GitHub

## ¿Qué es GitHub?
**Github** es una herramienta que permite almacenar el código en la nube, trabajar en colaboración con otro compañeros, también tiene herramientas para que los usuarios reporten errores o que ellos suban código para el programa.  
Te da herramientas para hacer una wiki, tienes la oportunidad de ver los commits anteriores, en caso que haya habido algún problema y no funcione algo.  Github ofrece muchas funciones más, por eso suele ser el que escogen las empresas.

## ¿Qué empresa hay detrás?
Github fue fundado el 8 de febrero de 2008 por *Tom-Preston-Werner*, *Chris Wanstrath*, *P. J. Hyett* y *Scott Chacon* y empezó como [Logical Awesome LLC](https://es.wikipedia.org/wiki/GitHub) y en Enero de 2010 renombraron la empresa a Github.  
El 4 de junio de 2018 **Microsoft compró Github** y desde entonces ellos tienen el control de la compañía.
